# ML From Scratch

Implementing machine learning algorithms from scratch in Python without sklearn.

## Algorithms
- Linear Regression
- Logistic Regression (IPL Dataset, 76.8% accuracy)
- KNN & Weighted KNN (Iris Dataset, 93.3% accuracy)
- Decision Tree and Gini Impurity (Wine Dataset, 90.7% accuracy)
- Random Forest (Wine Dataset, 97.75% accuracy)
- K-Means Clustering (Mall Customer Dataset)
