# 🚀 Machine Learning From Scratch

Implementing Machine Learning algorithms from scratch using **Python** and **NumPy** without relying on `scikit-learn` for the core algorithms.

---

## 📌 Purpose

This repository is part of my journey to become a Machine Learning Engineer.

Rather than treating Machine Learning as a black box, I aim to understand every algorithm from first principles by implementing it from scratch.

---

## 📚 Implemented Algorithms

| Algorithm | Dataset | Accuracy / Result | Implementation Highlights |
|-----------|---------|------------------:|---------------------------|
| Linear Regression | Synthetic Dataset | R² Evaluation | Gradient Descent, Cost Function (MSE), Feature Scaling |
| Logistic Regression | IPL Match Dataset | **76.8% Accuracy** | Sigmoid Function, Maximum Likelihood Estimation, Binary Cross Entropy |
| K-Nearest Neighbors (KNN) | Iris Dataset | **93.3% Accuracy** | Euclidean Distance, Majority Voting, Weighted KNN |
| Decision Tree | Wine Dataset | **90.7% Accuracy** | CART Algorithm, Gini Impurity, Recursive Tree Construction |
| Random Forest | Wine Dataset | **97.75% Accuracy** | Bootstrap Sampling (Bagging), Random Feature Selection, Majority Voting |
| K-Means Clustering | Mall Customer Dataset | Unsupervised | Lloyd's Algorithm, Centroid Updates, Euclidean Distance |
| Principal Component Analysis (PCA) | Height–Weight Dataset | Dimensionality Reduction | Covariance Matrix, Eigenvalues, Eigenvectors, Data Projection |
