# 🚀 Machine Learning From Scratch

Implementing Machine Learning algorithms from scratch using **Python** and **NumPy**, with the goal of understanding the mathematics behind each algorithm rather than treating them as black boxes.

---

## 📌 Purpose

This repository documents my journey toward becoming a Machine Learning Engineer by implementing core Machine Learning algorithms from first principles.

Each implementation focuses on understanding the underlying mathematics, optimization techniques, and intuition behind the model rather than relying on high-level libraries.

---

# 📚 Implemented Algorithms

## Supervised Learning

| Algorithm | Dataset | Accuracy / Result | Implementation | Concepts Covered |
|-----------|---------|------------------:|---------------|------------------|
| Linear Regression | Synthetic Dataset | R² Evaluation | **NumPy (From Scratch)** | Gradient Descent, Mean Squared Error (MSE), Feature Scaling |
| Logistic Regression | IPL Match Dataset | **76.8% Accuracy** | **NumPy (From Scratch)** | Sigmoid Function, Maximum Likelihood Estimation, Binary Cross Entropy |
| K-Nearest Neighbors (KNN) | Iris Dataset | **93.3% Accuracy** | **NumPy (From Scratch)** | Euclidean Distance, Majority Voting, Weighted KNN |
| Decision Tree (CART) | Wine Dataset | **90.7% Accuracy** | **NumPy (From Scratch)** | Gini Impurity, Recursive Tree Construction, Threshold Selection |
| Random Forest | Wine Dataset | **97.75% Accuracy** | **NumPy (From Scratch)** | Bootstrap Aggregation (Bagging), Random Feature Selection, Majority Voting |
| Support Vector Machine (SVM) | Breast Cancer Dataset | **95% Accuracy** | **NumPy (From Scratch)** | Hinge Loss, SGD, Soft Margin, Support Vectors, Maximum Margin Classification |
